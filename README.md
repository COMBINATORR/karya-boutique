# KARYA — бутик в ТРЦ «Насиха», Атырау

Сайт-визитка семейного бутика турецкого бренда KARYA: ассортимент, адрес, звонок и WhatsApp.

## Факты

- **Адрес:** г. Атырау, ТРЦ «Насиха», ул. Махамбета Утемисова, 116д, бутик 111, 1 этаж
- **Телефон / WhatsApp:** +7 (702) 312-69-98
- **Часы:** 10:00–20:00
- **Модель:** прямые закупки с завода KARYA (Турция) → продажа в Атырау
- **Продукт бренда:** натуральная итальянская кожа, фактуры, цвета; женская и мужская кожгалантерея

Контакты в коде: `src/constants/contact.js`  
Тексты: `src/locales/ru.json`, `src/locales/kk.json`

## Стек

- React 19 + Vite 8
- Tailwind CSS 4
- i18next (RU / KK)
- Framer Motion
- Lucide icons
- Vitest + Testing Library

## Локально

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
npm run preview
```
